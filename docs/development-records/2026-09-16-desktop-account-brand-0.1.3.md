# 桌面账号信息插件升级记录

日期：2026-09-16

## 范围

桌面 Profile 将内置品牌插件从 `@opc/dsh-brand@0.1.2` 升级至 `0.1.3`。该版本优先通过桌面 preload 提供的受限身份投影显示当前账号，避免依赖桌面 Host 中不存在的 `/auth/session` 路由。

## 安全边界

渲染进程仅可读取认证状态、用户标识和服务端返回的商户或账号显示名。Cookie、访问令牌、会话标识、账号密钥、密码和供应商凭据均不会进入 preload 投影或插件包。

## 验证

执行 Profile 定向测试、类型检查和桌面打包前的包内容检查；最终以正式 macOS App 的“设置 - 账号”页面显示实际账号信息为验收标准。
