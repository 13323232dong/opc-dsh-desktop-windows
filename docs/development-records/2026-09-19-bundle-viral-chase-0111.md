# 桌面端内置追爆插件 0.1.11

- 日期：2026-09-19
- 桌面版本：0.7.18
- 插件版本：`@opc/dsh-viral-chase@0.1.11`

本次升级修复 Agent 工具读取主人公锚点时，把 API 安全公开投影误过滤为空数组的问题。OPC API 已按当前登录身份限定锚点范围，公开响应不会暴露内部 `tenantId` 和 `userId`；桌面插件现在保留 API 返回的真实锚点 ID、名称及授权状态。

验收重点：同一账号下工作台显示的已授权“我的形象锚点_16.5s”，必须能被 `viral_chase_list_anchors` 查询，并用于生产报价；不得要求用户重新上传锚点。
