# 追爆创作音色目录与语音参数桌面集成

- 日期：2026-09-21
- 桌面版本：0.7.23
- 插件版本：`@opc/dsh-viral-chase@0.1.15`
- 平台主分支提交：`0b3fc8c`
- 功能范围：系统音色选择、最近选择置顶、更多音色弹窗，以及 MiniMax 语速、音调、音量参数透传

本次将追爆创作音色功能合入平台 `main`，并把重新构建的 `opc-dsh-viral-chase-0.1.15.tgz` 嵌入最新桌面主线。快捷区默认展示沉稳高管、温润男声、真诚青年、温暖闺蜜、新闻女声；本人克隆声音继续作为独立入口，不会被系统音色静默替换。

语音参数使用 MiniMax 已支持的范围：语速默认 1.0、音调默认 0（原音）、音量默认 100%，提交时分别映射到 `voice_setting.speed`、`voice_setting.pitch` 和 `voice_setting.vol`。修改音色或参数只更新任务生产输入，不会自动触发付费生成。

发布验收应核对插件包哈希、桌面完整测试、类型检查、品牌门禁、构建、macOS ARM64 打包及真实桌面 UI。当前构建无有效 Developer ID Application 证书，因此只能标记为未签名 macOS 内测/验收包，不作为公开签名发布。
