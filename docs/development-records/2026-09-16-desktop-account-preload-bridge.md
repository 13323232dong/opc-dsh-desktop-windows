# 桌面端账号显示预加载桥接开发记录

## 背景

桌面 DSH 的品牌插件不能稳定依赖 Host 扩展路由来读取当前账号。账号页因此可能已登录却显示“加载中”。

## 本次变更

- 新增 `desktopAccountProjection`，从已激活桌面身份中构造最小只读显示投影。
- 在 Electron 主进程注册 `desktop-auth:current-account`，仅允许当前主窗口主框架调用。
- 在预加载层暴露 `dshDesktopAuth.current()`，供受信任的桌面 DSH 渲染器读取。

## 安全边界

- 投影只包含 `authenticated`、用户标识、商户名称和账号名称。
- 明确不包含登录会话 ID、账号目录键、Cookie、访问令牌、密码或供应商密钥。
- 主进程继续验证调用来源；权限判断和租户隔离仍只使用稳定 ID。

## 验证

- 身份投影契约和登录入口定向测试共 17 项通过。
- TypeScript 类型检查通过。
- 后续与品牌插件 `0.1.3` 一同打包，在正式桌面账号页验证。
