# 桌面端账号身份插件包更新记录

## 背景

`@opc/dsh-brand` 已升级为 `0.1.2`，补充桌面模式的只读账号身份展示投影。桌面 Profile 仍固定使用 `0.1.1`，会导致应用即使重启也继续加载没有该能力的旧插件。

## 本次变更

- 将桌面 Profile 中 `@opc/dsh-brand` 的版本和制品名更新为 `0.1.2`。
- 重新打入已通过插件测试、类型检查和构建的 `opc-dsh-brand-0.1.2.tgz`。
- 更新 Profile 测试期望，确保缺少该制品时发布校验会拒绝构建。

## 验证

- 制品缺失时，发布制品测试正确失败并指出缺少 `opc-dsh-brand-0.1.2.tgz`。
- 加入制品后，Profile、发布制品、桌面认证和运行时定向测试共 14 项通过。
- TypeScript 类型检查通过。

## 安全与限制

- 插件包只包含 DSH 插件代码与静态资源，不包含账号、Cookie、令牌、密码或供应商密钥。
- 本记录仅完成包的集成准备；正式应用验收将在桌面核心身份传递合入后执行。
