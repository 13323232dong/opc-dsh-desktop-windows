# Evan超级管家：手动工具扣费界面需求

## 目标

让商户能单独查看由自己点击或确认执行的付费工具动作，而不必在完整对话轨迹中逐条寻找费用。

## 范围

- 新增“工具扣费”页面，展示音频生成、数字人、图片、视频、发布及其他手动触发的工具调用。
- 每条记录显示操作、所属任务、服务/模型、实扣积分、预扣、退款、状态和时间。
- 未扣费的已完成手动操作显示 `0`；自带 Key 显示平台扣费为 `0`，并注明由服务商结算。
- 点击记录可查看用量、计价版本和单价；可跳转至对应轨迹动作。
- 轨迹列表增加“扣费”列，轨迹详情增加“扣费”字段，使用同一账单记录。

## 数据口径

- 仅 `billingContext.actionId` 存在的实际工具或任务动作进入“工具扣费”页面。
- 聚合金额采用实扣减退款；预扣单列显示，不计入实扣。
- 读取范围由当前登录商户决定，客户端不传递商户身份。
- 无可靠关联的历史账单不进入工具页面，仍可在完整账单中标记为历史记录。

## 验收

1. 手动生成音频、图片或数字人后，在工具扣费页显示对应动作及实扣金额。
2. 未扣费的手动操作显示 `0`，不会留空或显示 `--`。
3. 预扣、结算、释放和退款分别显示，金额不会重复。
4. 轨迹列表和详情显示与工具扣费页相同的动作净扣费。
5. 不同商户和不同对话不串账；自带 Key 不被误写成免费。
