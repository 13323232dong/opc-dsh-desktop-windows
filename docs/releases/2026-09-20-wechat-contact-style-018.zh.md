# 微信联系人回复习惯 0.1.18

日期：2026-09-20。范围：本机 macOS 桌面 AI 客服插件，不发布服务器或远程更新。

## 实现

- 插件源码提交：`4b90679`，版本 `0.1.18`。
- AI 客服标签新增联系人回复习惯：读取已加载聊天、关系分类、编辑说明、预览、JSON 导出及删除。
- 以微信账号和联系人隔离存储；主要学习自己的出站文本，排除可识别的插件发送与草稿。
- 工作联系人使用现有业务知识检索；朋友、家人和未知关系不查询业务知识库。
- 生成阶段使用有限历史示例，不把旧价格或承诺当作当前事实。风格删除或更新使旧生成上下文失效。
- 不自动开启监听，不新增发送授权；保留当前仅写入微信草稿的使用方式。

## 边界

- 当前只读取微信已加载的一页文字，非全量历史导出；不能可靠识别全部历史 AI 文本。
- 存档保存在本机。回复时有限历史片段随上下文发送给当前配置的模型。
- 真实工作/生活联系人验收等待用户指定对象；不能用单元测试代替真实聊天验收。
