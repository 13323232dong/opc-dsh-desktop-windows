# Evan超级管家 0.7.60 原生微信标签不可用门禁记录

## 变更

- AI 客服标签范围弹层在微信未暴露原生标签时，明确显示 `WECHAT_TAGS_UNAVAILABLE`。
- 此状态下“保存并开启监听”不可点击；保存动作本身也会拒绝执行，防止残留选择状态绕过界面门禁。
- 内置 `@opc/DSH-ai-customer-service` 升级至 `0.1.25`，Profile、启动器映射与 release manifest 使用同一 artifact 和 SHA-256。

## 安全边界

- 不回退为本地标签、全局监听或名称猜测。
- 未修改候选回复、填入草稿或用户确认发送的边界；该插件不自动发送微信消息。
