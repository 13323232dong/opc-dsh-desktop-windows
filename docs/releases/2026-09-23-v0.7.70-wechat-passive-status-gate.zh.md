# Evan超级管家 0.7.70 发布记录

日期：2026-09-23

## 修复范围

- AI 客服面板启动和定时刷新只读取插件本地状态，不再调用微信原生 helper。
- 未点击“开始监听”时，不探测微信账号、不激活微信、不切换会话、不点击控件，也不恢复旧监听或旧发送任务。
- 移除当前微信版本无法稳定识别的标签管理入口，统一改为用户主动开启“全部微信私聊”监听。
- 全局监听继续排除公众号、服务号、订阅号和文件传输助手。

## 验收要求

启动桌面应用并打开 AI 客服标签，不点击“开始监听”，等待至少两个面板轮询周期。微信当前会话、前台状态和输入框必须保持不变。只有用户主动点击“开始监听”后，插件才可读取未读会话并生成草稿；草稿不得自动发送。

## 已知限制

本版本撤下微信标签监听入口。全局未读监听及草稿写入仍需单独完成真实 UI 验收，不能因单元测试通过而宣称全链路已跑通。
