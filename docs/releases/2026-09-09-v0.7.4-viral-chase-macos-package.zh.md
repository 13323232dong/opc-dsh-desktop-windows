# 伟东 OPC Desktop v0.7.4 追爆创作 Mac 集成记录

## 目标

将最新版 `@opc/dsh-viral-chase` 追爆创作插件和受控本地媒体运行时打入 macOS ARM64 桌面 App。发布包从干净的桌面 `main` 构建，不携带共享开发目录中的未提交文件。

## 本次更新

- 更新桌面 Profile 内的 `@opc/dsh-viral-chase@0.1.0` 固定插件包。
- 新增本地媒体运行时状态、安装、任务认领、执行、进度和取消能力。
- 媒体任务按桌面账号作用域隔离，运行时切换不会暴露真实账号、Session、本机路径或供应商凭证。
- FFmpeg 使用固定版本、固定下载域名、文件大小和 SHA-256 校验；校验失败的临时文件会被删除。
- Whisper Core ML、MoneyPrinterTurbo 和 HyperFrames 暂未提供审核后的桌面分发包，因此保持不可安装状态，不从运行时动态下载未知代码。
- 本地媒体执行器未配置时采用失败关闭策略，不会自动切换到付费云端 Provider。

## 安全与权限

- DSH 只能调用明确授予的 `media.status`、`media.install`、`media.claim`、`media.run`、`media.progress` 和 `media.cancel`。
- Broker 继续使用随机回环端口和每个 Runtime 的临时令牌。
- 请求只接受受约束的任务 ID、资产 ID、版本和内容哈希，不接受任意命令、脚本、本机路径或供应商 URL。
- 组件安装仅允许代码中固定的 HTTPS 下载项，并执行流式大小限制和 SHA-256 校验。

- 追爆插件：类型检查、构建和 59 项插件测试通过。
- 桌面定向测试：8 个测试文件、37 项测试通过。
