# 一键追爆音频生成入口 0.7.39

## 范围

- 追爆创作音频卡不再硬编码禁用“生成音频”。当当前脚本、镜头计划、预审与费用确认均有效时，它调用同一任务的受保护 `speech` 步骤，并使用该步骤返回的受保护音频文件进行试听。
- 未满足条件时，音频卡显示具体的下一步（保存文案、生成镜头计划、预审或确认费用），不把服务端审批门禁绕过为直接付费请求。
- 内置插件升级为 `@opc/dsh-viral-chase@0.1.26`，Profile artifact、bootstrap 映射和 release manifest 的文件名、版本与 SHA-256 已同步，已有账号会升级而非复用旧缓存。

## 验证

- 平台插件：101 项测试、类型检查、构建与包内版本核验通过。
- 桌面：121 个测试文件、906 项测试，类型检查、品牌校验、应用构建和 macOS ARM64 包验收通过。
