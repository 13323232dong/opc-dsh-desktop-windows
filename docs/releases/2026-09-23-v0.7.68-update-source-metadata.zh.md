# Evan超级管家 v0.7.68 发布记录

## 范围

修复 macOS 安装包内 `app-update.yml` 被 Electron Builder 按上游仓库地址推断为 GitHub 更新源的问题。该问题会让 Evan 客户端错误读取 `dataelement/dsh-desktop` 的上游版本并显示不属于本产品的更新提示。

## 修复内容

- 显式指定桌面安装包默认更新源为 `https://opc.ohmycode.cc/updates/latest/`。
- 增加发布契约测试，禁止将空的 `publish` 配置重新引入，从而阻止打包器回退推断上游 GitHub 源。
- 桌面版本从 `0.7.67` 递增至 `0.7.68`；正式发布后线上 macOS 清单必须与安装包版本完全一致。

## 已验证

- 全量单元测试：942 项通过。
- TypeScript 类型检查通过。
- macOS ARM64 打包通过。
- 最终包内 `app-update.yml` 为 generic provider，地址为 Evan 官方更新源，且不包含 `github`、`dataelement` 或上游仓库地址。

## 发布限制

本机构建未使用有效的 Developer ID 签名证书，仅可作为本机验证产物。正式公开更新仍需由已签名的正式发布流程上传 DMG、ZIP、blockmap 与 `latest-mac.yml`，再完成旧版检查、下载、重启和版本复核。
