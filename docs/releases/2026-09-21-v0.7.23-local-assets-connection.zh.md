# Evan超级管家 0.7.23 本地资产库连接修复

## 范围

- 修复资产部门显示“当前设备未连接本地资产库”的问题。
- 桌面 Runtime 注册 `local-assets` 能力，由主进程提供本地资产读写、预览、归档、检索和迁移入口。
- 本地资产按已认证账号的 `accountKey` 哈希隔离，Session 只用于业务审计，不作为资产目录身份。
- 浏览器插件不能提交可信账号范围、绝对文件路径或迁移包路径；上传、导入和导出通过桌面原生选择器完成。

## 根因

资产部门插件已经调用桌面本地资产 Broker，但正式 `main` 未包含 `LocalAssetsRuntime`，Runtime 也没有注册 `local-assets` capability。此前相关代码只存在于未提交的开发目录，没有进入正式构建。

## 验证

- `test/broker/local-assets-runtime.test.ts`
- `test/broker/local-capability-broker.test.ts`
- `test/runtime/opc-runtime-factory.test.ts`
- `npm run typecheck`
- 首次打包后发现身份签名密钥未从桌面主进程传入 Harness，导致浏览器代理路由未注册；在 `0.7.24` 修复并重新验收。

## 安全边界

- 每个账号使用独立哈希目录，不向前端暴露账号目录映射。
- 路径遍历、伪造本地源路径和未授权 capability 均被拒绝。
- 本地素材和知识库不回退到云端，不把凭据写入资产清单。

## 已知限制

- 本机构建若缺少有效 Developer ID 证书，只能作为未签名验收包，不能作为公开正式发行包。
