# v0.7.5 macOS 自动更新修复记录

日期：2026-09-13  
范围：DSH 桌面端 macOS/Windows 更新检查与回退版本目录。

## 已验证的问题

此前桌面端更新地址固定为 Windows 目录，即使应用运行在 macOS，仍会请求
`/updates/windows/`。线上没有为 macOS 公开 `latest-mac.yml`，因此已安装的
macOS 应用无法发现新版本，也不会显示更新确认卡。

## 本次修改

- 按运行平台选择更新源：macOS 使用 `/updates/mac/`，Windows 使用
  `/updates/windows/`。
- 回退版本索引支持按平台生成归档地址，避免 macOS 选择版本时下载 Windows 包。
- 将桌面版本提升至 `0.7.5`，作为 `0.7.4` 的可检测后继版本。
- 线上 Nginx 增加 macOS 更新目录静态路由。正式发布时该目录必须包含
  `latest-mac.yml`、对应 ZIP、blockmap 及归档目录。

## 验证结果

- `test/version-catalog.test.ts`：通过。
- `test/build-version-index.test.ts`：通过。
- `npm run typecheck`：通过。
- 平台路由测试：通过。

## 发布限制

自动更新只接受与当前 macOS 应用匹配、已签名并完成公证的 Release ZIP。未签名
本机构建可覆盖安装进行界面验收，但不能作为对网页下载用户的自动更新发布包。
