# Evan超级管家 0.7.24 本地资产代理身份修复

## 修复

桌面主进程已经加载 `OPC_DSH_IDENTITY_HMAC_SECRET`，但启动账号 Harness 时未传递该密钥。资产插件的浏览器代理因此直接关闭，资产部门误显示“当前设备未连接本地资产库”。

现在 Runtime 仅从桌面主进程环境读取身份签名密钥，并传给当前账号 Harness；浏览器和插件不能提交或覆盖密钥。

## 验证

- Runtime 回归测试确认密钥传递。
- Broker 直连返回 `connected: true`。
- 重启后通过资产部门页面点击“重试”验证代理连接。
- 完整发布验收包版本：`0.7.24`。
