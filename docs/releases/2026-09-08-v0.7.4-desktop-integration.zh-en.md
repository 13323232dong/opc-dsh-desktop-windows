# 伟东 OPC Desktop v0.7.4

## 发布主题 / Release Theme

桌面端功能主线整合版本：账号隔离、本地能力桥接、完整 OPC 插件 Profile，以及 Windows 自动更新能力统一进入 `main`。

Desktop integration release: account isolation, local capability bridging, the complete OPC plugin profile, and the Windows auto-update channel are now consolidated on `main`.

## 更新内容 / What's New

### 账号、登录与运行时 / Accounts, Login, and Runtime

- 每个账号拥有独立的 DSH Home、Workspace、日志和运行时目录，账号切换前会停止旧 Runtime 并清理旧路由。
- Each account now owns an isolated DSH Home, Workspace, logs, and Runtime directory. The previous Runtime and routes are closed before switching accounts.

- macOS 使用 Keychain 保存桌面会话凭据，凭据通过标准输入传递，不出现在命令参数或日志中。
- macOS credentials are stored in Keychain and passed through standard input, never through command arguments or logs.

- 桌面 Runtime 只有在身份验证完成后才会启动，Broker 使用随机回环端口和每个 Runtime 的临时令牌。
- The desktop Runtime starts only after identity verification. The Broker uses a random loopback port and an ephemeral token per Runtime.

### OPC 插件与工作台 / OPC Plugins and Workbench

- 发布 Profile 现在包含 Agent Teams、工具库、我的 Agent、资产、素材匹配、文件附件、实时语音、会话上下文、任务看板、飞书文档、抖音工作流、发布预检、生成式 UI 和品牌资源。
- The release Profile now includes Agent Teams, Tool Library, My Agents, assets, material matching, file attachments, realtime voice, session context, task board, Feishu documents, Douyin workflows, publish precheck, GenUI, and brand assets.

- 插件以可验证的本地包进入桌面资源目录，Profile 会检查依赖闭包，并拒绝客户端 bundle 中的 Node-only 模块。
- Plugins are shipped as verifiable local artifacts. Profile bootstrap validates dependency closure and rejects Node-only modules in client bundles.

- Agent Teams 的活动面板、成员导航、共享记忆、任务事件和交付物下载能力进入桌面发布基线。
- Agent Teams activity, member navigation, shared memory, task events, and deliverable downloads are part of the desktop release baseline.

### 本地能力与更新 / Local Capabilities and Updates

- Ego Lite 通过本地 Broker 访问受限浏览器能力，首批支持的导航范围为飞书域名。
- Ego Lite is accessed through the local Broker with a restricted navigation allowlist; the first supported navigation scope is Feishu domains.

- Windows 打包增加 OPC 发布清单校验和签名校验，统一使用桌面版本号 `0.7.4`。
- Windows packaging now verifies the OPC release manifest and signature, using the unified desktop version `0.7.4`.

- Windows 自动更新候选工作流已进入仓库，正式发布仍需完成签名和 GitHub Release 验收。
- The Windows auto-update candidate workflow is included. A production release still requires signing and GitHub Release verification.

## 已知事项 / Known Items

依赖审计仍报告 `dsh-ppt -> pptxgenjs -> image-size` 图片解析链的 4 个高危公告，当前上游没有可用自动修复版本。该依赖用于 PPT 能力，后续应升级或隔离图片解析器后再关闭告警。

Dependency audit still reports four high-severity advisories in the `dsh-ppt -> pptxgenjs -> image-size` image parsing chain. Upstream currently provides no automatic fix. This dependency is used by PPT capabilities and should be upgraded or isolated in a follow-up release.
