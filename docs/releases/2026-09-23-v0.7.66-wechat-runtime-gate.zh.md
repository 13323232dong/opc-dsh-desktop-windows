# Evan超级管家 v0.7.66 发布记录

## 范围

升级内置 `@opc/DSH-ai-customer-service` 至 `0.1.27`，修复桌面重启后未手动开启监听仍可能触发微信自动化的问题。

## 变更

- 插件启动时清除仅存在于内存的监听授权；历史持久化状态不能恢复微信监听。
- 未获本次明确开启监听指令时，后台定时器不扫描会话、不打开微信、不读取消息、不生成或写入草稿。
- 用户显式开启全局、标签或单联系人监听后才授予本次进程的监听权限；显式单条发送不受该监听闸门影响。
- Desktop Profile 与 bootstrap 均固定引用 `opc-DSH-ai-customer-service-0.1.27.tgz`。

## 制品

- 插件 SHA-256：`34a2946dd331173450a81d996ca61293610f42e8d64dbf001451237914ce5898`。

## 验收边界

- 插件自动化测试覆盖启动恢复后不进行监听动作；真实桌面仍须验证冷启动期间鼠标与微信窗口均未被占用。
- 手动开启后处理新未读消息、生成并写入微信草稿的真实验收尚未完成，不以构建或状态文件代替。
