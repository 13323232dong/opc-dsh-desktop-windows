# v0.7.8 桌面追爆 Broker 身份链路修复

日期：2026-09-16

## 修改内容

- 为桌面 Broker 增加严格限定的一键追爆 API 路由白名单。
- Broker 在验证本地运行时能力令牌后，向线上 API 注入可信桌面标记和受保护的登录 Cookie。
- Broker 丢弃插件携带的租户、用户和 Agent 身份字段，只保留 DSH 会话标识；线上 API 负责从登录会话恢复真实租户身份。

## 验证

- `npm test -- test/broker/local-capability-broker.test.ts`：10 项通过。
- `npm run typecheck`：通过。

## 安全说明

本次不把服务端 HMAC 密钥、登录 Cookie 或其他凭据写入桌面配置、插件包或日志。追爆任务的租户授权、费用确认与产物访问仍在服务器执行。
