# v0.7.7 桌面会话恢复修复记录

日期：2026-09-16  
范围：macOS 与 Windows 桌面端登录会话持久化。

## 问题与证据

`v0.7.6` 在 macOS 正式包启动时会回到登录页，并显示“无法验证登录状态”。
线上 `https://opc.ohmycode.cc/api/v1/auth/me` 可达，未认证请求按预期返回 `401`。
本机身份元数据存在，但旧版通过 `security add-generic-password -w` 以标准输入写入
Keychain 的方式没有保存会话值，导致无法恢复有效会话。

## 本次修改

- macOS 与 Windows 统一使用 Electron `safeStorage` 保存账户凭据。
- macOS 的 `safeStorage` 使用系统 Keychain；Windows 使用 DPAPI。
- 加密后的凭据仅以账户哈希文件名保存在应用数据目录，文件权限为 `0600`，不保存
  明文会话令牌。
- 缺少或无效的历史凭据会回到正常登录流程；用户重新登录一次后，后续会话使用新存储。
- 桌面版本提升到 `0.7.7`，让更新客户端能够识别修复包。

## 验证结果

- 账户存储、认证 Provider 定向测试：12 通过。
- 全量测试：842 通过。
- `npm run typecheck`、`npm run build`：通过。
- `gitleaks detect --no-git --source . --redact --exit-code 1`：未发现泄露。
